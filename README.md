# GLAMORA BEAUTY — Haute Parfumerie & Sensorial Cosmetics

A luxury editorial cosmetics storefront designed for modern high-end beauty e-commerce.

## ✨ Features
- **Editorial Homepage (`index.html`)**: Haute formulation showcase, editorial lookbook, bestselling lipsticks, powders, and foundation collections.
- **Collection / Shop All (`shop.html`)**: Complete product catalog with category navigation and filter pills.
- **Product Detail Page (`product.html`)**: "Lumière Velvet Matte Lip Couture" with shade selectors, formula ingredients, and luxury bag checkout actions.
- **Interactive Prototype Switcher**: Quick switching between all three views.
- **Local Server (`server.js`)**: Zero-dependency Node.js HTTP server.

## 🚀 Running Locally
You can run this project using Node.js:
```bash
node server.js
```
Or double-click `start.bat` on Windows.
Then open [http://localhost:3000](http://localhost:3000) in your browser.
